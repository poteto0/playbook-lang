# Playbook CodeMirror Demo

This is a demo of the Playbook language extension for CodeMirror.

## Getting Started

1.  Build the `code-mirror` package:
    ```bash
    cd ../../code-mirror
    npm install
    npm run build
    ```

2.  Install dependencies and start the demo:
    ```bash
    cd ../examples/codemirror-demo
    npm install
    npm run dev
    ```

## Features

- Syntax highlighting for Playbook files.
- Integration with CodeMirror's `basicSetup`.
- Dark theme using `@codemirror/theme-one-dark`.
